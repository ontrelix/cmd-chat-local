## How do we use it?


~~~
You have two files.

The first file, `phone.py`, should be run in Pydroid or any Python IDE on your phone. It 
will open a CMD-like terminal and display an IP address and port.

Then, go to your computer and run `computer.py`. First, enter the IP address and press 
Enter. Then, enter the port. The chat will then open.

1. You must connect both devices to the same network so they can communicate over the local
 network (LAN).
2. An internet connection is **not required**. You only need both
 devices to be connected to the same local network.
